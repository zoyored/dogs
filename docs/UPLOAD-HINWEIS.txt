Dieses Paket ist als Ergänzung/Strukturierung für https://github.com/zoyored/dogs gedacht.

Die vorhandene LICENSE im Repository bleibt bestehen und ist deshalb nicht im Paket enthalten.

Upload über die GitHub-Webseite:
1. ZIP lokal entpacken.
2. Im Repository "Add file" -> "Upload files" wählen.
3. Den INHALT des entpackten Ordners (nicht die ZIP selbst) in das Upload-Feld ziehen.
4. Commit message z. B. "Add Canicross and Canitrail calendar structure".
5. Commit directly to main.
6. Danach Settings -> Pages -> Deploy from a branch -> main /docs aktivieren.
